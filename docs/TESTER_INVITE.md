# Closed-test invite — for the 12 testers

Google requires **at least 12 testers opted in for 14 days in a row** before a
new personal developer account can publish. If someone leaves early, the
14 days can fail — so ask people who will actually keep it.

Before sending: in Play Console → Testing → Closed testing, add each tester's
Gmail to the list, then copy the **opt-in link** into `<OPT-IN LINK>` below.

---

## WhatsApp message (Tanglish)

> Hi! Naan oru app build pannirukken — **Life Mentor**. Habits, money, alarms, notes ellaam oru app-la. Login illa, ads illa, unga data phone-laye irukkum.
>
> Play Store-la release panna Google-ku **12 per 14 naal test** pannanum. Help pannuveengala? 🙏
>
> 1. Indha link open panni "Become a tester" press pannunga: <OPT-IN LINK>
> 2. Apram Play Store-la irundhu install pannunga.
> 3. **14 naal uninstall pannaadheenga.** Daily oru thadava open pannaa podhum.
> 4. Edhaavadhu problem, confusing-aa irundhaa idhe chat-la sollunga. Screenshot anupinaa innum nalla.
>
> Unga Gmail ID enna? Adha list-la add pannanum.

## What to ask testers after a week

1. Did your reminders arrive on time? (Phone brand?)
2. What confused you in the first 2 minutes?
3. Would you keep using it after the test? Why / why not?

Write the answers into PROGRESS.md. They decide what gets fixed before launch.
